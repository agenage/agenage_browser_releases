# Agenage Browser releases

<!-- user-request | 2026-10-26 | George | Publish audited browser release assets while keeping application source private. -->
Public binary releases for [Agenage Browser](https://agenage.com/). Application and website source repositories remain private.

Each release includes its package, SHA-256 checksum and a public release manifest with requirements, signature fingerprint and verified test scope. Preview limitations are stated in the release notes. No profiles, cookies, credentials, private signing material or test APKs are distributed.
